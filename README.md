# Python Temelleri ve Mini Projeler

Python öğrenme sürecimde geliştirdiğim temel pratikler ve konsol tabanlı mini projeler.

## Projeler

1. **[Proje 1 - Temel Veri Yapıları ve Öğrenci Not Hesaplama](./PROJE1.ipynb)**
   - Kullanıcıdan girdi alma, metin (string) dilimleme, liste ile not ortalaması hesaplama, sözlük (dictionary) ve küme (set) kullanımı.

2. **[Proje 2 - Akıllı Quiz Uygulaması](./proje2_akilli_quiz.ipynb)**
   - Döngüler ve koşullu ifadelerle geliştirilmiş; menü, puanlama, seviye belirleme ve en yüksek skor takibi içeren etkileşimli quiz oyunu.

3. **[Proje 3 - Kullanıcı Yönetim Sistemi](./proje3_kullanici_yonetim_sistemi.ipynb)**
   - Fonksiyonlar kullanılarak oluşturulan; kullanıcı ekleme, listeleme, yaş/şehir filtreleme ve benzersiz yetenekleri görüntüleme uygulaması.

## Kullanılan Teknolojiler
- Python 3
- Jupyter Notebook
